# MQTTower (public)

This repository is the **public, open-source** mirror of MQTTower.  
Pull requests are welcome here.

## Relationship to the private development repository

Development happens primarily in a **separate private repository** (FinalFactory). That repo may contain internal tooling, CI secrets, and **AI-assisted development artifacts** (e.g. Cursor rules, prompts, or generated drafts) that must **not** appear in this public tree.

**Only** content that is intended for open-source distribution is committed here. There is no AI-specific or secret material in this repository by design.

## Contributing

Open PRs against **this** GitHub repository. Maintainers sync changes between the private repo and this public repo as needed.
